# DODGE BALLS!!


 hello!! well my actual first expirience with pygame after learning basic syntax
 This is a really really simple game about dodging projectiles while collecting coins and powerups!
 yes i know this is REALLY generic 
 however i hope you find it as cool as i did coming from someone who was coding on scratch! 
 going from 4 blocks for movement to like 40 lines of code to move is really cool to me haha and i hope u enjoy my makeshift graphics ## and game play! 


**TO BE Played BY DOWNLOADING THE source code.** link to the itch.io -->  https://r5u5d.itch.io/dodge-balls
extract the file first,then double click "main.py" ( you need to have python installed) 
run pip install pygame in the console if pygame isnt installed.
